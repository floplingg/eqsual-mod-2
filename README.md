# Eqsual Cosmetics

Free 3D head cosmetics for **Minecraft Java 1.21.11** (Fabric). Crowns, hats and seasonal collections — every cosmetic is free and permanently available. No rarity, no locks, no paid items, no loot boxes, no exclusives.

## Install
1. Install [Fabric Loader](https://fabricmc.net/use/) 0.18.1+ for 1.21.11.
2. Put **Fabric API** (0.141.3+1.21.11 or newer) and `eqsual-cosmetics-1.0.0.jar` in `.minecraft/mods`.
3. In game press **K** (rebind in *Options → Controls → Key Binds → Eqsual Cosmetics*).

Install it on a server too (same jar) so other players can see your cosmetics.

Cosmetics use three slots — **Head**, **Ears**, **Halo** — so you can wear e.g. a crown + bunny ears + a halo at once. Equipping something in a used slot swaps it.

## Menu
- Rotating 3D preview of your own player (drag to rotate/tilt, scroll to spin). Clicking a card *tries it on* in the preview.
- Search (name, tags, collection), filter chips (All / Favorites / Equipped / each collection), favourites (☆ on a card or the details bar; favourites sort first).
- Equip / Unequip button, double-click a card to toggle, "Equipped" list with × to remove, Unequip all.
- Toggles: **Glow**, **Anim**ations, particle **FX**, show **Others**' cosmetics.
- Everything saves to `config/eqsual_cosmetics.json`.

## Rendering
- Real 3D cuboid models with a custom texture atlas, attached to the head bone (follows head yaw/pitch, sneaking, swimming…).
- Visible in third person (F5), on other players and in the menu. In first person your own head isn't drawn, so cosmetics never block your view.
- Optional emissive glow, procedural animations (flickering flames, spinning snowflake, bobbing halo, twitching ears, swaying hat tips) and ambient particles.
- Lightweight: static parts are pre-baked; each cosmetic is at most three draw submissions.

## Multiplayer
- Server + client both have the mod → your loadout is sent on join and on every change; the server relays it to everyone, sends newcomers the current loadouts, and clears them when a player leaves.
- Server without the mod → **client-side fallback**: you still see your own cosmetics; the menu shows "Local only".
- Players without the mod are never sent unknown packets. The server validates ids, one-per-slot and rate-limits updates.

## Building
```
./gradlew build          # -> build/libs/eqsual-cosmetics-1.0.0.jar
./gradlew runClient
./gradlew runClientGameTest   # dev-only runtime smoke test (renders every cosmetic, opens the menu via the keybind)
```
Java 21, Gradle 9.2.1 (wrapper), Fabric Loom 1.14, Mojang mappings.

### Editing / adding cosmetics
Models, textures and menu icons are generated by `tools/gen_cosmetics.py` (Python 3 + Pillow):
```
python3 tools/gen_cosmetics.py
```
It writes `src/main/resources/eqsual_cosmetics/cosmetics.json` (parts, UVs, animations, particles), `textures/cosmetic/atlas.png` and `textures/gui/icons.png`. Model space is in pixels with the origin at the top-centre of the head, +Y up, +Z towards the face.
